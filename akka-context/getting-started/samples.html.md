# Samples and blueprints

Two ways to start from this catalog:

- **Clone a sample** — a complete, prebuilt app you download and run. Best when you want working code to read or adapt.
- **Generate from a blueprint** — a recipe that the [Akka Specify Plugin](../sdk/spec-driven-development.html) turns into runnable AI systems. We have 460 more examples for you to explore.
